# minitel_gc

Une plaforme d'amusement pour le Minitel, conçu pour fonctionner sur un Raspberry connecté par le port périphérique du Minitel


## ATTENTION

Tout le projet a été fait et programmé par LLM (Gemini dans ce cas), c'est un projet d'amusement avec aucune envie d'être rééelement serieux, même si c'est cool finalement
